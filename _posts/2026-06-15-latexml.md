I've recently been reading <i>Joy of Cryptography</i> by Mike Rosolek, and realized I could probably use some formal proof-writing practice, given that it's been a while since I've had to write very thoroughly mathematically-sound proofs (Computer science and its consequences). Then, I decided I also wanted to learn how to render math on the web without JavaScript, because it would be cool. Two birds with one scone, you know...
<br><br>
So, I looked online and found MathML, a markup language for expressing mathematical notation on webpages. Although it's unfortunately not universal, it's a W3C standard supported by most modern browsers, which sounded good enough to me.
I might be a bit stupid, though, because I started by writing MathML by hand before realizing it's not meant to be written manually at all.
That led me to this <a href="https://tex.stackexchange.com/questions/227195/latex-to-mathml-conversion-tools-limitations-and-approaches" target="_blank">Stack Exchange</a> post, which led me to <a href="https://math.nist.gov/~BMiller/LaTeXML/ussage.html" target="_blank">LaTeXML</a>, a command line tool for converting LaTeX into MathML.
I noticed LaTeXML errors for some macros, but felt that unless I would be using the software very extensively, it'd be easier to apply a bit of manual post-processing instead of making my own customizations to the tool itself. Though, I could look into that some other time, if I feel like it...
<br>
Anyway, to produce MathML code, I started by using the latexmlmath command to convert each mathematical expression, because its command output is very legibly spaced and formatted. That way, I could easily make my own changes wherever necessary. Then, I decided to switch to using the latexmlc command for faster, bulk conversion of sections that didn't need as many manual adjustments.
<br><br>
Below are a few exercises I selected from <i>Joy of Cryptogrpahy</i> that I felt would make nice formalization practice, while also not being overly trivial.
(That said, these proofs still have the vibe of rigorously proving something fairly obvious, anyway...)
